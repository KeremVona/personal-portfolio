# Projects Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Projects placeholder with a card grid, a project panel (side panel on desktop, bottom sheet on phones), placeholder media, and painted bouquets in the section's bottom corners.

**Architecture:**
- Project data stays in typed content. Pure helpers (grid classes, tag truncation, links) are unit-tested.
- One native `<dialog>` shows whichever project was opened. Its slide and fade come from plain CSS in `index.css` (`@starting-style` plus `allow-discrete`), with no animation library.
- The bouquets are committed WebP masters cut by a script from the private hero PNGs, served through vite-imagetools.

**Tech Stack:** what's already there (React 19, TS 7, Tailwind v4, vite-imagetools, sharp for scripts, Vitest). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-21-projects-design.md`

## Global Constraints

- **Grid:** 1 column on phones; `md` (768px) 2 columns; `lg` (1024px) up to 3. The column count never exceeds the project count. No empty slots.
- **Card:** a white card (`rounded-card`, `shadow-card`), with a 16:10 cover, an `h3` name (Inter Tight 600, ~18px), a one-line summary (~14px, `ink-soft`), up to 4 tag pills then "+N", and a footer row ("Open source"/"Closed source" · "Read more →").
- **Stretched button:** `<article>` › `h3` › `<button aria-haspopup="dialog">` whose `::after` covers the card. The `:focus-visible` ring wraps the whole card. Hover lifts −4px over 300ms (`motion-safe` only).
- **Bouquets:** left and right in the section's bottom corners, behind the cards, about `clamp(150px, 22vw, 340px)` wide. Phones show only the left one, at ~44vw. They are still, `alt=""` and `aria-hidden`, and never cover card text.
- **Panel:**
  - A native `<dialog>` with `showModal()`, labelled by its heading.
  - Closes on ×, Escape or a backdrop click. Focus returns to the card's button. The page doesn't scroll behind it.
  - **≥ md:** right side, full height, `min(520px, 92vw)` wide, cream, a left-edge shadow, a backdrop of `rgb(28 42 30 / 0.3)`. Slides from the right in ~350ms ease-out.
  - **< md:** a bottom sheet, full width, `max-height: 92dvh`, top corners rounded ~18px. Slides up. No grab handle.
  - **Reduced motion:** fade only.
- **Panel order:** × (≥ 40×40px, `aria-label="Close"`), name (~26–28px), description, media, "What I built" list, "Built with" pills (omitted when the stack is empty), links, and a small bouquet at the foot (bottom-right).
- **Links:**
  - "View on GitHub": a primary pill, `bg-ink text-cream`, shown when `repoUrl` is set.
  - "Live site": a secondary pill, shown when `liveUrl` is set.
  - "Closed source": quiet text, shown when there's no `repoUrl`.
  - External links use `target="_blank" rel="noreferrer"`.
- **Media:**
  - **Placeholder** when `media` is empty: a gradient in the project's tone, labelled "Screenshots coming soon".
  - **Images:** WebP variants with `srcset`/`sizes`, `width`/`height` and `loading="lazy"`.
  - **Video:** at most one, self-hosted. `controls muted preload="none"`, with a poster; never autoplays.
  - **Gallery:** one main item, with thumbnails when there's more than one item.
- **Reveal:** each card is wrapped in `Reveal` with `delay = index * 0.08`.
- **Copy:** placeholder. The section title is "Things I've built".
- **Gate before each commit:** `npm test && npm run typecheck && npm run lint && npm run format:check && npm run build`

## Review Focus

1. **Reopening with a different project:** the panel shows the new project's content, scrolled to the top, with the gallery back on its first item. It never flashes the previous project's content.
2. **Clicks inside the panel:** clicking its padding, text or empty space must not close it. Only the dimmed area does.
3. **Focus after closing:** whether closed by Escape, × or the backdrop, focus lands back on the card that opened the panel.
4. **Scroll lock:** the page can't scroll behind an open panel, and on Windows desktop the layout doesn't jump sideways when the scrollbar disappears.
5. **At 360px:** no horizontal scroll (bouquets, open sheet); a long name wraps; the sheet scrolls internally when its content is taller than the screen.

Items 1–5 are UI behaviour in a real browser. Task 4 checks each by script in the Browser pane (Vitest here covers pure logic only, by project convention).

### Task 4: The project panel

**Files:**
- Create: `src/sections/projects/ProjectPanel.tsx`
- Modify: `src/sections/Projects.tsx`, `src/index.css`, `README.md`

**Interfaces:**
- Consumes: `ProjectItem`, `projectLinks`, `visibleTags` (via `stack.length`), `MediaPlaceholder`, `BOUQUET_RIGHT`.
- Produces:
  ```ts
  export interface ProjectPanelHandle { open: (project: ProjectItem) => void }
  export const ProjectPanel: React.FC<{ ref: React.Ref<ProjectPanelHandle> }>  // React 19 ref-as-prop
  ```

- [ ] **Step 1: Write the panel CSS in `src/index.css`** under `@layer components`, using `.project-panel` on the `<dialog>`:
  - **Base (phones):**
    - `margin: auto 0 0; width: 100%; max-width: 100%; max-height: 92dvh;`
    - `border-radius: 18px 18px 0 0; background: var(--color-cream); padding: 0; border: 0;`
    - `translate: 0 100%;`
    - `transition: translate .35s cubic-bezier(.2,.8,.2,1), display .35s allow-discrete, overlay .35s allow-discrete;`
  - **`[open]`:** `translate: 0 0`, and `@starting-style { translate: 0 100% }` inside it.
  - **`@media (min-width: 768px)`:**
    - `margin: 0 0 0 auto; height: 100dvh; max-height: 100dvh; width: min(520px, 92vw); border-radius: 0;`
    - `box-shadow: -14px 0 44px rgb(30 50 30 / .2);`
    - Closed and starting state `translate: 100% 0`.
  - **`::backdrop`:** `background: rgb(28 42 30 / .3)`, with `opacity` 0 → 1 using the same transition and `@starting-style` pattern.
  - **`@media (prefers-reduced-motion: reduce)`:** `translate: none` in every state, and the panel itself transitions `opacity` 0 → 1 instead.
  - **Scroll lock:** `html:has(.project-panel[open]) { overflow: hidden; scrollbar-gutter: stable; }`.
- [ ] **Step 2: Build `ProjectPanel`.**

  - **Keep the content mounted after close,** so the closing slide still shows it.
  - **Content order** follows Global Constraints → Panel order.
  - Key the gallery by `project.slug`, so its selected index resets.

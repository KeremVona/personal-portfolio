# Sky Hero Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The hero becomes Kerem's computer-on-a-cloud picture. The cloud is a separate layer placed right of the copy, and it shies away from a nearby cursor.

**Architecture:**
- **The art:** a sharp script splits `reference/647386481.png` into a background layer (the cloud removed, the sky filled and deepened behind the copy) and a cloud layer with alpha. It also writes the cloud's box in source pixels.
- **Pure, tested TypeScript** places the cloud for a given hero size: it never overlaps the copy column, and it computes the shy target offset and the spring step.
- **A small hook** applies placement on resize, and the shy motion on pointer moves, with `translate`/`rotate` on the cloud `<img>`.

**Tech Stack:** React 19, TypeScript 7 (strict), Tailwind v4, vite-imagetools, sharp (scripts only), Vitest. Checks use headless Chrome over CDP against `npm run preview`.

**Spec:** `docs/superpowers/specs/2026-11-24-sky-hero-design.md`

## Global Constraints

- **Source art:** `reference/647386481.png` (2730×1536). It's git-ignored and must never be committed, and no raw PNG may be committed either.
- **Wide layout:** the cloud's centre sits about 64% across (allowed 60–68%), and the copy column is at most about 50% of the hero's width. They never overlap: the cloud shrinks or moves right instead.
- **Shy motion only when** `(hover: hover) and (pointer: fine)` and `prefers-reduced-motion: no-preference`, and **not** in the `narrow` layout (`max-aspect-ratio: 6/5`). Otherwise the cloud stays still.
- **Shy feel:**
  - radius ≈ 1.3× the cloud's half-width;
  - maximum offset ≈ 28px at a 1440px-wide hero, scaled with the hero's width;
  - tilt up to 2°;
  - a soft spring with no snap and no overshoot;
  - no idle bobbing;
  - the cloud has `pointer-events: none`.
- **Hero text is cream, AA on real pixels at the 26 hero sizes.** The contrast comes mainly from deepening the sky in the background layer.
- **The hero's phone image weight** stays near today's (about 235 KB).
- **The gate before every commit:** `npm test && npm run typecheck && npm run lint && npm run format:check && npm run build`.
- **Branch:** `feat/sky-hero`, cut from `main`.
  - Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - The final reviewer is a **Sonnet** subagent.

## Review Focus

1. **Placement at in-between aspect ratios** (1024×768, 1280×600, 1100×900, 1920×700): the cloud's box never intersects the copy's box and stays below the nav. Pinned by `placeCloud` tests and the Task 3 pixel check.
2. **The cut-out pushed to its maximum offset** in four directions: no halo, hole, ghost or horizon band. Pinned by the Task 1 preview composites.
3. **The cursor leaving the window mid-push:** the cloud floats back to rest instead of freezing. Pinned by the Task 4 check (dispatch a `pointerout` with no related target, then rest within 2s).
4. **A narrow window with a mouse, and touch devices:** the cloud never moves. Pinned by the Task 4 check at 700×1000 and with emulated touch.
5. **The transparent nav at the very top over the deep sky:** its text passes AA. Pinned by the Task 3 contrast check (nav items included).

### Task 2: Placement and shy logic (pure, tested)

**Files:**

- Create: `src/sections/hero/heroArt.ts` (imports the box JSON; exports `ART = { width: 2730, height: 1536 }`, `CLOUD_BOX` and `PORTRAIT_LEFT`)
- Create: `src/sections/hero/cloudLogic.ts` and `cloudLogic.test.ts`

**Interfaces:**

- **`coverScale(hero: Size, art: Size): number`**: `max(hero.width / art.width, hero.height / art.height)`.
- **`placeCloud(hero: Size, opts: { copyRight: number; navBottom: number; centreX?: number }): Rect`**
  - **Size:** the cloud's natural size is `CLOUD_BOX` × `coverScale`. The background is drawn `object-cover` centred, `object-position: 50% 50%`, so its natural top is `(hero.height - ART.height * scale) / 2 + CLOUD_BOX.top * scale`.
  - **Centre:** its centre is `hero.width * (centreX ?? 0.64)`.
  - **Shrink:** it shrinks, keeping its aspect ratio and its vertical centre, until the left edge is ≥ `copyRight + 24`, the right edge ≤ `hero.width - 16`, and the top ≥ `navBottom + 16`.
  - **Right first:** before shrinking, it moves right up to `hero.width * 0.68`.
  - **Returns** `{ left, top, width, height }` in hero pixels.
- **`shyTarget(pointer: Point | null, centre: Point, radius: number, max: number, maxTilt = 2): { x: number; y: number; tilt: number }`**
  - Away from the pointer, magnitude `max * (1 - d / radius)`.
  - Zero when the pointer is null, `d >= radius` or `d < 1`.
  - `tilt = maxTilt * (x / max)`, leaning away horizontally.
- **`clampToRoom(offset: Offset, room: { left: number; right: number; up: number; down: number }): Offset`**: clamps x to `[-left, right]` and y to `[-up, down]`, leaving the tilt alone.
- **`springStep(state: Spring, target: Offset, dt: number): Spring`**
  - `Spring = { x, y, tilt, vx, vy, vtilt }`.
  - Critically damped, with stiffness `k = 70`, damping `2 * sqrt(k)`, `dt` clamped to ≤ 1/30.
- **`isAtRest(state: Spring, target: Offset): boolean`**: everything within 0.1 and the velocities below 0.5.

- [ ] **Step 1: Write the failing tests.**
  - `placeCloud`:
    - at 1440×900 with `copyRight` 690 and `navBottom` 64, the result's centre is within 2px of 0.64×1440, and `left` ≥ 714;
    - at 1024×768 with `copyRight` 512, `left` ≥ 536, `right` ≤ 1008, and the width is less than the natural width;
    - at 1920×700, `top` ≥ 80 and `right` ≤ 1904;
    - the aspect ratio always equals `CLOUD_BOX`'s, to 0.01.
  - `shyTarget`:
    - null gives 0;
    - a pointer 10px right of the centre with radius 200 gives x ≈ −0.95·max (away, leftward) and y ≈ 0;
    - a pointer at `d = radius` gives 0;
    - a pointer below the centre gives a negative y;
    - the tilt sign follows x.
  - `clampToRoom`: `{x: -30, y: 10}` with room `{left: 12, …}` gives x = −12.
  - `springStep`, stepped at 1/60 from rest toward x = 28:
    - after 0.5s x > 20;
    - it never exceeds 28.3;
    - `isAtRest` is true by 2s;
    - a `dt` of 1 behaves like 1/30.

  Run: `npx vitest run src/sections/hero`

  Expected: FAIL, because the module is missing.

### Task 4: The shy cloud

**Files:**

- Create: `src/sections/hero/useShyCloud.ts`
- Modify: `src/sections/Hero.tsx`

**Interfaces:**

- Consumes `shyTarget`, `clampToRoom`, `springStep` and `isAtRest`.
- Produces `useShyCloud(hero: RefObject<HTMLElement | null>, cloud: RefObject<HTMLImageElement | null>): void`.

- [ ] **Step 1: Implement.**
  - **Gate:** a `matchMedia` for `(hover: hover) and (pointer: fine) and (prefers-reduced-motion: no-preference) and (min-aspect-ratio: 6/5)`, re-evaluated on `change`. When it doesn't match, reset the cloud's `translate`/`rotate` and do nothing else.
  - **While the hero intersects** (IntersectionObserver), listen to `pointermove` on `window`. Store the last pointer in page coordinates, and set it to null on `pointerout` with no `relatedTarget` (leaving the window) and on `blur`.
  - **The loop:** on each move, start a rAF loop if none is running. Each frame:
    - centre = the cloud's placed centre (from its `offsetLeft`/`offsetTop`/size, so it isn't affected by the current translate);
    - radius = 1.3 × half its width;
    - max = 28 × hero width / 1440;
    - target = `clampToRoom(shyTarget(...), room)`, where the room keeps it right of `copyRight + 8` and inside the hero;
    - step the spring with the real `dt`;
    - write `translate: Xpx Ypx` and `rotate: Tdeg`.
  - **Stop** when `isAtRest` is true and the target is 0.
- [ ] **Step 2: Wire it** into `Hero.tsx` after `useCloudPlacement`.
- [ ] **Step 3: Checks (CDP).** Desktop 1440×900:
  - a mouse moved to 60px left of the cloud's centre moves it right (translate x > 5 within 500ms);
  - moved far away, it's back to `translate: none`, or within 0.5px, within 2s;
  - pushed, then a `pointerout` with no related target makes it return within 2s;
  - reduced motion emulated: it never moves;
  - 700×1000 with a mouse: it never moves;
  - with touch emulated (`Emulation.setTouchEmulationEnabled` plus mobile metrics): it never moves.

  Expected: all pass.

- [ ] **Step 4: Gate**, then **commit** `feat: the cloud shies away from the cursor`.

# About Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the About placeholder with layout A:
- the koi watercolour shown whole as a tilted print (whole on wide screens, on top on phones),
- short placeholder text and fact pills,
- an eyebrow-style section heading,
- the site's first scroll reveal, built on `motion`.

**Architecture:**
- About copy lives in typed content, and the fact pills are derived from `PROFILE`.
- The painting goes through the same pipeline as the hero: a committed WebP master from a script, plus vite-imagetools variants.
- `Section` gains a way for a section to place its own heading.
- A shared `Reveal` wrapper uses `motion/react` through `LazyMotion` with `domAnimation`.

**Tech Stack:** what's already there, plus `motion@14` (`motion/react`, which re-exports framer-motion's `LazyMotion`, `domAnimation`, `m`, `MotionConfig`).

**Spec:** `docs/superpowers/specs/2026-11-21-about-design.md` (it builds on the foundation spec).

## Global Constraints

- **Layout A:**
  - Wide screens (≥ 768px, i.e. Tailwind `md`): print column ~38%, gap ~6%, columns vertically centred, paragraphs max ~58ch.
  - Phones: one column; the print on top at ~68% of the width, capped at **320px**, left-aligned.
- **The print:**
  - The whole image, paper border included; never cropped.
  - `rotate(-1.6deg)`; shadow `0 14px 30px -12px rgb(30 50 30 / .35), 0 2px 6px rgb(30 50 30 / .08)`.
  - On hover-capable devices only (`@media (hover: hover)`), it straightens to 0° and lifts `-4px` over 300ms. No hover motion with reduced motion.
  - Alt text: "Watercolour painting of koi fish swimming among lily pads".
  - Placeholder background `#f2ead8` (the paper tone).
  - Explicit `width`/`height`, `loading="lazy"`, `decoding="async"`.
- **Heading:** an eyebrow "About" (Inter Tight 600, ~13px, letter-spacing ~0.08em, uppercase, `meadow-deep`), then `h2` "A little about me". The `h2` keeps `id="about-title"` and the section's `aria-labelledby`.
- **Pills:**
  - Built from `PROFILE.location`, `formatGraduation(PROFILE.graduation)` → "Graduating June 2027", and `PROFILE.languages.join(' · ')`.
  - `bg-meadow-tint`, `text-meadow-deep`, rounded-full.
- **Image variants:**
  - Master `src/assets/about/koi.webp`: q90, 1200px wide, from `reference/671.png` via `npm run art:about`.
  - Variants 480 / 720 / 960 px, WebP q80, `as=metadata`, with `srcset`/`sizes`. `sizes` = `(min-width: 768px) 38vw, min(68vw, 320px)` (the builder may tune it).
- **Reveal:**
  - `opacity 0 → 1` and `y 20 → 0`, once, 0.6s ease-out, as it enters the viewport (`viewport={{ once: true, amount: 0.25 }}`).
  - A 0.12s stagger: print first, then text.
  - Reduced motion uses `MotionConfig reducedMotion="user"` (opacity only, no movement).
  - Reveal wraps the print's wrapper, never the `<img>` itself.
- **Copy:** placeholder from the spec §3, kept in typed content. It includes the visible "[a hobby or two]" slot.
- **Quality:**
  - Lighthouse mobile: Performance ≥ 90; Accessibility, Best Practices and SEO ≥ 95.
  - CLS 0; no horizontal scroll at 360px.
- **Workflow:**
  - Branch `feat/about`. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nothing is pushed.
  - The gate: `npm test && npm run typecheck && npm run lint && npm run format:check && npm run build`

## Review Focus

1. **Tilt overflow:** the rotated print and its shadow at 360px must not cause horizontal scroll or clip awkwardly. *(Task 3, Step 4)*
2. **Image loading after the reveal:** a slow image inside an already-revealed wrapper shows the paper-coloured box, never a jump or an empty hole (CLS 0). *(Task 3, Step 4; Task 5)*
3. **Reduced motion:** content is visible without movement. A reveal that never fires must never leave content invisible. *(Task 4, Step 4)*
4. **No JavaScript or blocked observers:** content hidden by the reveal's initial state must not stay hidden if the IntersectionObserver never fires. Anything already in view on load must show (a deep link to `#about`). *(Task 4, Step 4)*
5. **Other sections:** Projects, Experience and Contact still render their headings with working anchors after the `Section` change. *(Task 2, Step 3)*

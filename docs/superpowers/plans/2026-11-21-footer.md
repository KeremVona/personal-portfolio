# Footer (Contact) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the footer placeholder with option A, "Night meadow": a dark contact section with an email button, "Copy email", links, the painted flower band edge to edge, and a bottom strip.

**Architecture:**
- The copy lives in `src/content/contact.ts`. Pure helpers (the copyright line, the clipboard check) are unit-tested.
- The band is a committed WebP master composited by a script from the private hero PNGs, served through vite-imagetools.
- `SectionHeading` gains a `tone` prop.

**Tech Stack:** what's already there; `lucide-react` for the mail icon.

**Spec:** `docs/superpowers/specs/2026-11-21-footer-design.md`

## Global Constraints

- **Footer:** `bg-ink text-cream`, with a hard edge after Experience. Content in the `max-w-6xl` container via `Section` (`id="contact"`, padding about `pt-16 sm:pt-24 pb-10`).
- **Type and colour:**
  - Eyebrow: `text-meadow` (the dark tone).
  - `h2`: cream, `clamp(2rem,5vw,3.75rem)`, `max-w-[14ch]`, keeping `id="contact-title"`.
  - Lead: `text-cream/78`, `max-w-[46ch]`.
- **Email button:** `bg-cream text-ink` pill with a `Mail` icon and `PROFILE.email`; `href={LINKS.email.href}`.
- **Copy button:**
  - Outlined (`border-cream/30`).
  - Rendered only when `canCopy(navigator)` is true.
  - On success: the label reads "Copied ✓" for 2000ms, and a polite live region says "Email address copied".
  - On a rejected write: the label stays the same and nothing is announced.
- **Links:** LinkedIn, GitHub and Résumé (PDF) from `LINKS`, with a 2px `decoration-meadow` underline and `underline-offset-4`. External links use `target="_blank" rel="noreferrer"`; the résumé keeps `download="Kerem-Can-Bas-Resume.pdf"`.
- **Focus ring inside the footer:** a light ring (`focus-visible:outline-cream`), since cornflower is too dark on ink.
- **Band:**
  - Crop y 560–1536 of the 2730×1536 art, composited from `5` (stems), `2` and `1`, back to front.
  - Full width, still, `alt=""`, `aria-hidden`, lazy, `srcset`.
  - Never narrower than 720px (centred); height capped at 700px, cropped from the top.
- **Bottom strip:** `bg-[#16221a]`, `text-cream/70`, ~13px, with "© {year} {name}" and a "Back to top ↑" link to `#top`. The items stack on phones.
- **Reveal:** the content block is wrapped in `Reveal`; the band isn't.
- **Gate before each commit:** `npm test && npm run typecheck && npm run lint && npm run format:check && npm run build`

## Review Focus

1. **At 360px:** no horizontal scroll from the 720px band. The flowers show at both edges.
2. **At 1920px:** no flower head is cut at the top of the band. At 2560px the cap applies and the bottom stays intact.
3. **Keyboard on dark:** each link and button shows a visible light focus ring.
4. **"Copy email":**
   - Success shows "Copied ✓" and the live region text.
   - Where the clipboard is unavailable, there's no button.
   - Repeated clicks don't stack timers or leave "Copied" stuck.
5. **Contrast:** AA for the eyebrow, lead, links and bottom strip on ink and `#16221a`.

Items 1–4 are checked in headless Chrome over CDP against `npm run preview`, since the Browser pane freezes animations and IntersectionObserver when hidden. Item 4's timer is also covered by keeping a single timeout ref (code). Item 5 is computed.

### Task 3: The footer

**Files:**
- Modify: `src/components/SectionHeading.tsx`, `src/sections/Footer.tsx`
- Create: `src/sections/footer/CopyEmailButton.tsx`

**Interfaces:**
- Consumes: Task 1's helpers and Task 2's art.
- Produces: `SectionHeading` gains `tone?: 'light' | 'dark'` (default `'light'`), where `'dark'` sets the eyebrow to `text-meadow`. Also `export function CopyEmailButton(props: { email: string }): JSX.Element | null`.

- [ ] **Step 1: Add the `tone` prop to `SectionHeading`.** Existing callers are unchanged.
- [ ] **Step 2: Build `CopyEmailButton`.**
  - `canCopy(navigator)` is checked in a lazy `useState` initializer; when it's false, render `null`.
  - `onClick` awaits `navigator.clipboard.writeText(email)`, then sets `copied` to `true`. A timeout ref clears any previous timer, resets after 2000ms, and is cleared on unmount.
  - The live region is a sibling `<span role="status" className="sr-only">`, holding "Email address copied" while `copied` is true.
- [ ] **Step 3: Rewrite `Footer.tsx`.**
  - `<footer className="bg-ink text-cream">` › `Section` (`id="contact"`, `className="pt-16 pb-10 sm:pt-24"`, `heading` = `SectionHeading` with `tone="dark"` and title `CONTACT.title`, heading size overridden per Global Constraints).
  - **Heading size:** if `SectionHeading`'s fixed `text-3xl sm:text-4xl` can't be overridden cleanly, add an optional `titleClassName` prop. Ledger the choice.
  - Children: the lead, the actions row, and the links row, all in `Reveal`.
  - **Band:** a `<div className="relative h-[min(calc(max(100vw,720px)/2.797),700px)] overflow-hidden">`. Inside, the `<img>` is `absolute bottom-0 left-1/2 w-[max(100%,720px)] max-w-none -translate-x-1/2`. Its `srcSet` comes from the `?w=720;1280;1920;2730&format=webp&quality=80&as=metadata` import, with `sizes="max(100vw, 720px)"`. (2.797 = 2730/976.)
  - **Bottom strip:** `flex flex-col gap-2 sm:flex-row sm:justify-between`. The copyright comes from `copyrightLine(PROFILE.name, new Date())`, computed once at module scope.
  - **Focus ring:** every interactive element in the footer gets `focus-visible:outline-cream`, or add `footer :focus-visible { outline-color: var(--color-cream) }` to `index.css`. Pick one and ledger it.
- [ ] **Step 4: Check headlessly** with `shot.mjs` against `npm run build && preview`, for each Review Focus item:

  - (2) 1920×1080 and 2560×1440: the band's height (≈686 at 1920, ≤700 at 2560), plus screenshots.
